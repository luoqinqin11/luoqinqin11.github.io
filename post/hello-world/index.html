我的第一个 Hugo 博客：从零到一搭建静态站点

2026-03-10

为什么选择 Hugo？

Hugo 是一款基于 Go 语言开发的静态网站生成器，相比 Jekyll、Hexo 有以下优势：

  • 编译速度极快（毫秒级生成全站）
  • 无需依赖 Node.js/Python 等运行时
  • 主题生态丰富，易扩展

搭建步骤回顾

  1. 安装 Hugo 二进制文件
  2. 创建新站点：hugo new site my-ivy-site
  3. 安装 Ivy 主题：git clone https://github.com/yihui/hugo-ivy.git themes/hugo-ivy
  4. 配置 config.toml
  5. 编写第一篇文章：hugo new post/hello-hugo.md
  6. 本地预览：hugo server -D

下一步计划

  • 自定义主题样式（修改 CSS）
  • 部署到 GitHub Pages
  • 集成评论系统（Waline）
  • 增加文章分类和标签
